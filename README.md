# 🐍 Jeu Snake - 2D (JavaScript)

Un jeu Snake classique développé en HTML5, CSS3 et JavaScript natif (Canvas API).

## 🌟 Fonctionnalités
- **Mécanique à 2 pommes** : Pomme rouge (+1 point) et Pomme dorée (+3 points).
- **Contrôles fluides** : Système anti-suicide empêchant les demi-tours instantanés.
- **Gestion du score** : Sauvegarde automatique du meilleur score (*High Score*) via `localStorage`.
- **Système de pause et Game Over** : Contrôle complet au clavier (Touches `P`, `Échap` et `Espace`).
- **Support des contrôles** : Flèches directionnelles et ZQSD.
